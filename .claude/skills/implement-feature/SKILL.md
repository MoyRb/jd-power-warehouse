---
name: implement-feature
description: Implement a feature using requirements, tests and review
---

1. Read product and architecture documentation.
2. Define clear acceptance criteria.
3. Identify affected modules and authorization boundaries.
4. Implement the smallest coherent solution.
5. Add automated tests.
6. Run lint, type checks and relevant tests.
7. Review security implications.
8. Update progress and explain unresolved risks.
